# 🚦 Road Traffic Violation Management System

> **Role:** Business Analyst | **Type:** Academic Project  
> **Duration:** 12/2024 – 11/2025 | **Instructor Evaluation:** 9.8/10

---

## 📌 Project Overview

Business analysis and system design for an end-to-end road traffic 
violation processing system supporting violation recording, online 
fine payment, dispute handling, and statistical reporting for both 
citizens and traffic enforcement authorities.

---

## 👥 System Actors

| Actor | Description |
|-------|-------------|
| 🧑‍💼 Citizens | Look up violations, pay fines online, submit disputes |
| 👮 Traffic Enforcement Officers | Record violations, process disputes, generate reports |

---

## ⚙️ Core Functional Modules

| # | Module | Description |
|---|--------|-------------|
| 1 | 📋 Violation Recording | Officers record violations and create official records |
| 2 | 🔍 Violation Lookup | Citizens and officers search violation history |
| 3 | 💳 Online Fine Payment | Citizens pay fines through the system |
| 4 | 📣 Dispute Handling | Citizens submit and track violation disputes |
| 5 | 📊 Statistics & Reporting | Generate analytical reports for management |

---

## 📐 System Analysis Documentation

| Diagram | Purpose |
|---------|---------|
| IFD (Information Flow Diagram) | Models information flows between entities |
| BFD (Business Function Diagram) | Decomposes business functions of the system |
| Context Diagram | Shows system boundary and external entities |
| DFD Level 0–2 (Data Flow Diagram) | Details data flows across all processes |
| ERD (Entity Relationship Diagram) | Models database structure |

---

## 🗄️ Database Design (SQL Server)

Key entities designed and normalized:

- `VIOLATION` — violation records and details
- `VEHICLE` — vehicle information
- `OFFICER` — enforcement officer profiles
- `RECORD` — official violation documents
- `CITIZEN` — citizen accounts
- `FINE_PAYMENT` — payment transactions
- `DISPUTE` — dispute submissions and status

---

## 🖥️ UI Design (Figma)

Screens designed for **Traffic Enforcement Officer** actor:

- 🔐 Login Screen
- 📝 Violation Entry & Record Creation Screen
- 📣 Dispute Processing Screen
- 📊 Statistics & Report Generation Screen
- 🔍 Violation Lookup Screen
